# Core Storage package

This built-in package owns small reusable storage UI cards. English is bundled
with each card; optional locale packs load only when their language is active.

`measuring` supplies the shared loading label used while storage data is being
calculated. `scan-status` owns the scan button and completion-state labels.
`growth-status` supplies the accessible descriptions for file-size movement.
`operations` owns account-database export and retention-rollup status copy.
`purge` owns the guarded retention-clear dialog vocabulary.
`offender-status` owns the status vocabulary used in storage offender tables.
`offender-size` owns their size and hard-link explanations.
`offender-columns` owns their stable column and type labels.
`offender-status-help` explains changed, absent, and dashboard-deleted paths.
`delete-results` owns confirmation and result text for individual deletion.
`bulk-delete` owns the equivalent selected-row controls and result notices.
`log` owns viewer navigation, search, and line-metadata labels.
`inspector-actions` owns the inspected-path action panel vocabulary.
`inspector-preview` owns image-preview state and dimension labels.
`history` renders the per-path size and file-count chart.
`inspector-breakdown` owns inspection breakdown and sort labels.
