# License status

The intended commercial model is source-visible self-hosting: customers may
install and modify Zogograph for their own internal use, while unauthorized
redistribution, resale, and competing hosted copies remain prohibited.

The final license text requires legal review and an owner decision. Until an
approved `LICENSE` file is added, this repository does not grant a new public
redistribution license by implication. Releases must not claim an open-source
or commercial license before that decision is recorded.

When approved, add the complete license text as `LICENSE`, identify its version
and effective date here, and update release notes, `THIRD_PARTY_NOTICES.md`,
and `SBOM.cdx.json` if the license changes dependency obligations.
